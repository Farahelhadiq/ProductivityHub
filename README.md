## <img src="https://cdn-icons-png.flaticon.com/512/1828/1828884.png" width="22" alt="Overview Icon" /> Overview

**ProductivityHub** is a modern, minimalist dashboard that helps users **track tasks, goals, workouts, and personal progress**. It features a clean UI system with a focus on **clarity, motivation, and daily routine optimization**.

## <img src="https://cdn-icons-png.flaticon.com/512/1828/1828743.png" width="22" alt="Features Icon" /> Key Features

✔️ **Login and Register pages** with clean, flat design  
✔️ **Dashboard layout** with 4 main cards: ToDo, Workouts, Goals, Stats  
✔️ **Task management** with checkboxes, emoji icons, and progress bars  
✔️ **Workout planner** with dynamic content and filters  
✔️ **Goal tracking system** with visual indicators (circular/bar)  
✔️ **Dark/light theme ready**  
✔️ **Responsive and mobile-first design**

## <img src="https://cdn-icons-png.flaticon.com/512/1087/1087815.png" width="22" alt="UI Design Icon" /> UI Design Guidelines

🎨 **Typography:** Roboto / Open Sans  
📐 **Spacing:** Clean layout (20–40px gutters), soft rounded edges  
🔵 **Accent Colors:**  
- Blue `#3B82F6` (buttons, highlights)  
- Green `#10B981` (progress bars)  
- Pink/Red brain icon for branding  
🌙 **Dark Theme Ready**
